# Sources de données

## Natural Earth Vector — terres émergées 1:110m

- Fichier intégré : `data/ne_110m_land.geojson`
- Couche : `ne_110m_land` (127 formes géographiques au moment de l'intégration)
- Source : https://github.com/nvkelso/natural-earth-vector
- Données : domaine public selon la licence officielle Natural Earth : https://github.com/nvkelso/natural-earth-vector/blob/master/LICENSE.md
- Attribution facultative recommandée : « Made with Natural Earth ».

Cette couche sert uniquement de fond physique mondial simplifié. Elle ne doit pas être utilisée comme une représentation des frontières politiques de 1444. Son échelle 1:110m convient à la vue planétaire initiale ; des données à plus grande échelle seront nécessaires pour les zooms régionaux.

## World Atlas TopoJSON

Le dépôt https://github.com/topojson/world-atlas redistribue des données dérivées de Natural Earth sous forme TopoJSON (licence ISC pour le code et le paquet). Il a été étudié mais aucun de ses fichiers n'est embarqué dans le jeu à ce stade.
